# 照着已有的 PPT 做新的

先看懂原来那份怎么讲，再用它当模板做新的。样子跟原来一致，内容换成新的。

## 步骤

1. **找到那份 PPT。** 用户没说清是哪份：`kb_search`（`kind` 用 `slides`）或 `search_files`（`*.pptx`）找候选，多个就 `ask_user` 让用户选。
2. **看结构。** `pptx_outline`：有几页、每页的版式、标题怎么写、每页几条要点、哪些页有表格和图表、备注怎么写，以及有哪些版式可用（标着 `write_pptx_uses_for` 的就是会被用上的）。
3. **找新内容。** 新的数字和事实从用户给的文件或资料库里找（`excel_query`、`excel_read`、`kb_search`）。要算的用 `excel_query` 或 `run_python`，不要心算。
4. **列大纲。** 按原来那份一页一页对应着列：页数和顺序参照原来的，标题的写法照原来的（原来是结论句就写结论句），每页要点条数差不多。用 `todo_write` 记下来；拿不准时 `ask_user` 让用户看一眼。
5. **生成。** `write_pptx`，`template` 填原来那份文件，`path` 写一个新文件名（不要覆盖原来的）。要点前面空两格是下一级。
6. **汇报。** 说清楚：
   - 哪些地方是照着原来的（页数、顺序、版式、标题写法）；
   - 哪些数字是新填的、出自哪里，哪些需要用户核对；
   - 原来有图表、图片的页：新的这份只有文字，图表要用户自己插（数据在哪里）。
   - 在 Hspace 里做的：最后一页或汇报末尾列出用到的资料来源（文件名和出处）。
7. **问一句要不要存成技能。** “这份汇报的结构要不要存成技能？以后做同类汇报直接照这个来。”用户同意就用 `skill_save` 存：写清页数、每页讲什么、标题写法、数据从哪里取、用哪份文件当模板。

## 容易出错的地方

- 原来的数字原样留在新的里：每个数字都要换成新的，或者标“待补充”。
- 模板里没有合适的版式时，`write_pptx` 会在结果的 `note` 里说明用了默认画法，要告诉用户。
- 不要改动原来那份文件。
